# Contributing

Thanks for looking. I'm not accepting pull requests: this is a personal project and I'd like to keep the code in one head. Issues are welcome, though, both bug reports and ideas.

For a bug, say which game (F1 24 or F1 25, with or without the 2026 Season Pack), which platform it runs on, which UDP format it's set to, the OS the server runs on, and paste what the server printed around the time it went wrong. `RE_LOG_LEVEL=DEBUG` gets more out of it. If it's about something the engineer said, the question and its answer help, and so does the lap.

For an idea, describe the moment in a race where you wanted it. That tells me more than a feature description does.
